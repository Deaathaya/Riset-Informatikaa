# Dataset

NASA C-MAPSS, subset FD002 dan FD004 (data latih bawaan).

- Sumber: Kaggle, "NASA Turbofan Jet Engine Data Set" oleh behrad3d — https://www.kaggle.com/datasets/behrad3d/nasa-cmaps (diakses 21 Nov 2026)
- Sumber asli: A. Saxena, K. Goebel, D. Simon, and N. Eklund, "Damage propagation modeling for aircraft engine run-to-failure simulation," *Proc. PHM*, 2008, doi: 10.1109/PHM.2008.4711414
- Format: 26 kolom tanpa header, dipisahkan spasi (nomor mesin, siklus, 3 operational setting, 21 sensor).
